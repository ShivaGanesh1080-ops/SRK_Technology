# SRK Design System

## 1. Brand Identity
- **Name:** SRK (Sri Radha Krishna Pvt. Ltd.)
- **Tagline:** Connecting Students, Skills & Industry
- **Personality:** Modern, Ambitious, Student-first, Practical, Technology-driven, Trustworthy.

## 2. Typography
- **Primary Font:** Plus Jakarta Sans
- **Characteristics:** Clean, legible, modern geometric sans-serif suitable for premium EdTech.
- **Hierarchy:**
  - `h1`: Bold, tight tracking for hero sections.
  - `h2`: Semi-bold for section headers.
  - `body`: Regular weight, readable line height for content.

## 3. Color Palette
- **Primary:** Deep Navy / Blue (Professional, trustworthy)
- **Secondary / Accent:** A subtle modern accent color (e.g., a vibrant teal or clean indigo) for CTAs.
- **Background:** White (`#FFFFFF`) with off-white (`#FAFAFA`) for subtle section contrast.
- **Text:** Dark slate (`#0F172A`) for primary text, gray (`#64748B`) for secondary text.
- **Status Colors:** Standard green (success), red (error), yellow/amber (warning).

## 4. UI Elements
- **Cards:** Clean borders, subtle shadows, no excessive rounded corners.
- **Buttons:** Solid primary buttons, subtle outline secondary buttons. Clear focus states.
- **Forms:** React Hook Form + Zod, clear labels, validation error messages in red below fields.
- **Icons:** Lucide React (clean, consistent line icons).

## 5. Animation (Framer Motion)
- **Guidelines:** Minimal and meaningful. No excessive bouncing or long delays.
- **Usage:**
  - Hero section text fade-up.
  - Section reveal on scroll (fade and slight translate Y).
  - Hover states on workshop cards (slight lift and shadow increase).

## 6. Accessibility
- All text must meet WCAG AA contrast ratios.
- Interactive elements must be keyboard navigable with clear focus outlines.
- Semantic HTML tags (`header`, `main`, `section`, `footer`) must be used.
