# SRK Route Map

## 1. Public Routes
- `/` - Homepage
- `/about` - Founder Story and Vision
- `/workshops` - Browse all workshops
- `/workshops/[slug]` - Workshop Details & Registration Entry
- `/domains` - Browse all technical domains
- `/domains/[slug]` - Domain Details
- `/students` - Information for Students
- `/colleges` - Information for Colleges & Partnership
- `/trainers` - Trainer Roster (Future)
- `/contact` - Contact Form
- `/faq` - Frequently Asked Questions
- `/privacy` - Privacy Policy
- `/terms` - Terms & Conditions

## 2. Authentication Routes
- `/login` - User Login
- `/register` - Student Registration
- `/forgot-password` - Password Recovery

## 3. Student Routes (Protected)
- `/student` - Dashboard Overview
- `/student/workshops` - Registered/Completed Workshops
- `/student/registrations` - Pending Registrations
- `/student/certificates` - Earned Certificates
- `/student/profile` - Profile Settings
- `/student/settings` - Account Settings

## 4. College Routes (Protected)
- `/college` - College Dashboard
- `/college/request-workshop` - Request Form
- `/college/requests` - Status of Requests
- `/college/profile` - College Profile

## 5. Admin Routes (Protected)
- `/admin` - Overview Metrics
- `/admin/workshops` - Workshop CRUD
- `/admin/registrations` - Manage Registrations
- `/admin/students` - User Management
- `/admin/colleges` - Manage Partnerships
- `/admin/trainers` - Manage Trainers
- `/admin/certificates` - Manage Certificates
- `/admin/payments` - Transaction History
- `/admin/feedback` - Workshop Feedback
- `/admin/analytics` - Platform Analytics
- `/admin/settings` - Global Settings
